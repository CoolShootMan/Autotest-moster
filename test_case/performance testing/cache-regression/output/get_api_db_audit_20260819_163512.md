## 判定口径

- 首次请求（冷启动/预热）DB>0 视为正常穿透，仅记录不判定违规；
- 同一 GET URL 第 2 次及以后仍 DB>0 → 缓存未命中，判定违规并抛出；
- 非 2xx 响应的 DB 计数不可信，不参与违规判定；
- header_integrity_check 的 /feature-flag/ 探测请求已过滤；
- DB=-1 表示 X-DB-Query-Count header 缺失（后端埋点未部署）。
